# 📐 Theodolite Survey MCP Server (Virtuoso Edition)

Профессиональный MCP-сервер для автоматизации инженерных, геодезических и архитектурных работ. От полевых измерений до высокоточной CAD-совместимости и чертежей, соответствующих ISO.

![Construction Site Plan](docs/gallery/construction_site_plan.png)
*Пример: План участка, соответствующий ISO, со стандартизированным штриховкой материалов и отсчетными сетками.*

---

## 🌟 Основные возможности

- **Профессиональный рендеринг:** Высококачественный вывод в PNG и **векторный SVG** с выделяемым текстом, соответствием веса линий ISO и идеальным масштабированием.
- **Высокоточная геодезия:** Автоматический метод Боудича (правило компаса) и **метод наименьших квадратов (МНК)** для уравнивания геодезических сетей.
- **Инфраструктурное проектирование:** Продольные профили для трубопроводов и дорог с вертикальным превышением и автоматически рассчитанными таблицами уклонов («подвалами»).
- **Архитектурное проектирование:** Профессиональные планы этажей с толстыми стенами, штриховкой материалов (ISO 128-50) и динамическими блоками мебели/сантехники.
- **Управление строительством:** Отчеты геодезической съемки «как построено» с векторами отклонений (план/факт) и картограммами объемов земляных работ.
- **Научная геодезия:** Поддержка эллипсоидов (WGS84, Красовский), проекций Гаусса-Крюгера/UTM и 7-параметрических преобразований Гельмерта.
- **Глобальная совместимость:** Полная поддержка **23 языков** и строгое соответствие **ISO 5457, 7200, 3098, 129-1 и 128-50**.

---

## 📂 Структура проекта

- `src/theodolite_mcp/` - Основная логика приложения (движок МНК, геодезические вычисления, рендеринг).
- `examples/` - Демонстрационные скрипты для всех основных сценариев использования.
- `docs/gallery/` - Визуальные примеры сгенерированных чертежей, соответствующих ISO.
- `tests/` - Надежный набор модульных тестов, покрывающих пограничные случаи и пиксельно-точный рендеринг.
- `output/` - Директория по умолчанию для сгенерированных PNG и DXF файлов.

## 🛠 Доступные MCP-инструменты

### 🖋 Профессиональный рендеринг (PNG/SVG)
- **`draw_plot_plan`** / **`draw_plot_plan_svg`**: Генерирует кадастровые, топографические и планировочные чертежи, соответствующие ISO.
- **`draw_longitudinal_profile`** / **`draw_longitudinal_profile_svg`**: Генерирует инженерные профили с автоматически рассчитанными таблицами уклонов/глубин.
- **`draw_interior_plan`** / **`draw_interior_plan_svg`**: Генерирует архитектурные планы этажей со стенами, проемами и мебелью.
- **`draw_construction_as_built_report`** / **`draw_construction_as_built_report_svg`**: Генерирует схемы отклонений и планы объемов земляных работ.
- **`draw_pipeline_schematic`** / **`draw_pipeline_schematic_svg`**: Генерирует технологические схемы трубопроводов (P&ID) по ISO 6412/14617.

### 📂 CAD-совместимость (DXF)
- **`export_to_dxf`**: Экспортирует любой PlotPlan в многослойный файл, совместимый с AutoCAD.
- **`export_profile_to_dxf`**: Экспортирует инженерные профили в DXF с правильным вертикальным превышением.

### 📐 Геодезия и вычисления (МНК)
- **`adjust_network_least_squares`**: Научная ajusting сетей по модели Гаврилова-Маркова.
- **`adjust_traverse_network`**: Стандартный Боудич-аджaust для теодолитных ходов.
- **`compute_parcel_area`**: Точный расчет площади по формуле Гаусса для многоугольника.

### 🧭 Геодезия и преобразования
- **`transform_coordinate_system`**: 7-параметрическое преобразование Гельмерта (WGS84 ↔ Локальная система).
- **`project_coordinates_gauss_kruger`**: Проецирует геодезические координаты на плоскую сетку X, Y.
- **`compute_inverse_geodetic_problem`**: Вычисляет расстояние/азимут между точками.
- **`dms_to_decimal_degrees`** / **`decimal_degrees_to_dms`**: Преобразования форматов углов.

## 🚀 Быстрый старт

Убедитесь, что установлен Python 3.10 или выше.

```bash
# Установите сервер
pip install .

# Запустите профессиональную демонстрацию
PYTHONPATH=src python3 examples/virtuoso_dam_project.py  # Высокоточный мониторинг
PYTHONPATH=src python3 examples/demo_interior_full.py     # Архитектурная планировка
PYTHONPATH=src python3 examples/demo_profile.py           # Профиль трубопровода
```

## 📐 Промышленное соответствие

Этот сервер создан для инженеров, а не просто разработчиков. Каждый вес линии, высота шрифта (osifont) и поле соответствуют требованиям **ISO по технической документации**, что делает выходные данные пригодными для официальных чертежей и юридически значимых инженерных отчетов.
